# Frontend Quiz App

HTML, CSS ve JavaScript ile hazırlanmış, çoktan seçmeli **Frontend Quiz** uygulaması.

## Özellikler

- **Konu Seçimi:** **HTML**, **CSS**, **JavaScript** ve **Accessibility** kategorilerinden birini seçerek teste başlama.
- **Soru ve İlerleme Takibi:** Soru sırası, ilerleme çubuğu, şık seçimi, boş seçim uyarısı ve doğru/yanlış cevap kontrolü.
- **Açık / Koyu Tema:** Üst bardaki anahtar ile açık ve koyu tema arasında geçiş yapabilme.
- **Sonuç ve Tekrar Başlama:** Quiz sonunda toplam puanı görüntüleme ve **Play Again** butonuyla konu seçim ekranına dönüp yeni bir kategori seçebilme.

## Kullanılan Teknolojiler

- **HTML5**
- **CSS3** (Grid, Flexbox, Responsive Media Queries, Light/Dark Tema)
- **JavaScript (Vanilla JS)** (DOM manipülasyonu ve olay dinleyicileri)
